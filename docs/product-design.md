# dsh 对话浮窗 · 产品设计（v0.3 / MVP）

> 2026-11-19 · 状态：自绘紧凑界面 + 真实会话，已通过 20+ 项自检

## 1. 一句话

在别的软件里干活时，把 dsh 对话压在最上层，不切屏就能追问、看结果。

## 2. 问题与边界

- **痛**：查 dsh 必须切窗口，打断心流；单屏/全屏时更明显。
- **做**：随时唤起、始终置顶的对话小窗，直接接同一套会话。
- **不做**：替代主窗、团队协作、移动端。

## 3. 形态与交互

| 项 | 规格 |
|---|---|
| 窗口 | 独立无边框窗口，默认 480×600（逻辑），拖边角自由缩放，下限 340×470、上限 820×1000 |
| 置顶 | 始终 `HWND_TOPMOST`，可一键取消；不占任务栏 |
| 唤起 | `Ctrl+Alt+F` / 托盘双击；标题栏 `—`、`✕` 收起到悬浮球 |
| 界面 | 自绘紧凑对话：会话条 + 气泡流 + 工具调用条 + 输入区 |
| 会话 | 右上「会话」切换历史；「＋ 新会话」直接建；记住上次打开的会话 |
| 悬浮球 | 56px 圆形置顶，单击回浮窗、可拖动，右键退出 |
| 记忆 | 尺寸、位置、置顶、球位置、dsh 端口写入 `config.ini`，删掉即复位 |

**为什么不用官方 Web 客户端**：官方页面是桌面+移动两套布局，压到 480 宽只能走移动版，信息密度大、留白少，用户反馈「太挤」。自绘界面只保留对话本身。

## 4. 功能清单

**已做**：独立置顶小窗、自由缩放、热键唤起、悬浮球、托盘常驻、会话列表/切换/新建、**按工作区分组 + 全局置顶区（可折叠、可搜索、可置顶/取消）**、历史消息分页（最近 24 条）、发送、停止、定时刷新、**文件拖拽/选择/粘贴上传（≤6 个、单个 ≤20 MB，作为 dsh 附件发送）**、**Markdown 代码块（语言标签 + 一键复制）**、行内代码与加粗、思考过程折叠、工具调用与结果折叠条、断线重试、诊断模式。

**未做**：真流式（当前生成中显示「正在生成…」，完成后整条出现）、更早历史加载、多浮窗。

## 5. 技术路线

```
DshFloat.exe（WinForms + WebView2）
   ├─ 本地桥接服务 HttpListener (127.0.0.1:3083+)
   │     GET  /                → DshFloatUI.html（自绘界面）
   │     POST /rpc/<method>    → 包装成 dsh RPC 信封，转发 127.0.0.1:3082/api/<method>
   └─ WebView2 → 桥接地址（同源，避开 3082 无 CORS 头的问题）
```

- **零补丁**：不改 `app.asar`，dsh 升级不受影响。
- **RPC 协议**（已实测）：`{"type":"client-request","rpcId":"…","method":"session/list","payload":{"args":{…}}}`
  - `session/list` → `args:{_request:{}}`，返回 `items[]`（标题、cwd、running、tokenUsage）
  - `session/page` → `args:{request:{address:{kind:"session",sessionId},maxMessages}}`，返回 `records[]`
  - `session/prompt` → `args:{request:{requestId,sessionId,mode:"queue",content:[{type:"text",text}],clientTimeZone}}`
  - `session/state` / `session/cancel` → `args:{request:{sessionId}}`
- **依赖**：WebView2 Runtime（Win11 自带）+ dsh 在跑 + 3082 可用。

## 6. 风险

1. **端口**：`3082` 默认端口，`config.ini` 可改；自动探测未做。
2. **流式**：dsh 的流式走 `/api/remote.mux` 多路复用通道，尚未接入，故生成期只有占位提示。
3. **全屏独占游戏**：Windows 限制，置顶窗口可能被盖住。
4. **热键冲突**：`Ctrl+Alt+F` 被占用时注册失败，暂无提示。
5. **附件**：已接入 `fileUploads/upload`；大文件上传期间没有百分比进度，单文件上限 20 MB。

## 7. 验收标准

- 全屏软件下能唤出，压在前台应用之上；标题栏可拖动、边角可缩放。
- 会话条显示真实标题；气泡区显示历史消息；发送后能收到完整回复；停止可用。
- 断线（dsh 未启动）显示重试提示，恢复后自动可用。
- 收起到悬浮球后单击可恢复，位置被记住；退出后无残留进程。
- `DshFloat.exe --test` 全部 PASS、退出码 0。
